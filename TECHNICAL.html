Cache Effectiveness

Z Skills relies heavily on Anthropic's prompt-cache. CLAUDE.md, SKILL.md bodies, and recent session context all live in cache windows; each subagent dispatch hits the cache instead of re-paying full input rates.

Methodology

Code/test/commit counts

All reproducible from a clean checkout of main at 283db23 (the merge-base this branch was cut from):

find skills block-diagram -type f \( -name "*.md" -o -name "*.sh" -o -name "*.py" \) -exec cat {} + | wc -l
find tests -type f -name "*.sh" -exec cat {} + | wc -l
find hooks -type f -name "*.sh*" -exec cat {} + | wc -l
git rev-list --count main
git log --oneline main | grep -cE '\(#[0-9]+\)'
gh issue list --state all --limit 1000 --json number | python3 -c 'import json,sys; print(len(json.load(sys.stdin)))'

Tokens & cost

Scanned 1,518 JSONL files under ~/.claude/projects/*zskills*/ (8 project working dirs — main repo + 7 ephemeral worktree-spawned project dirs), extracted the usage object from each assistant turn (including the nested cache_creation.ephemeral_5m_input_tokens / ephemeral_1h_input_tokens for the structured cache-tier split), summed per model, applied published Anthropic rates per turn. Full methodology lives in COSTS.html.

  • Rate basis: Opus 4.5+ tier rates ($5/$25/$6.25/$10/$0.50 per MTok for input/output/5m-cache-write/1h-cache-write/cache-read) for all 99,439 Opus turns, Haiku 4.5 rates ($1/$5/$1.25/$2/$0.10) for the 5,811 Haiku subagent turns. Earlier model tiers (Opus 4.0/4.1, deprecated) are 3× these rates — the cut took effect with Opus 4.5 on 2025-11-24. Real billing may differ (volume discounts, contract terms); actual out-of-pocket was a Claude Max x20 plan plus overflow usage spend, not API list rates.
  • Coverage gap: First commit on main is 2026-03-26; earliest logged JSONL turn is 2026-04-18 (two days after the Opus 4.7 release on 2026-04-16). The ~23 unlogged days ran on Opus 4.6 (same billing tier as 4.7) and contribute $0 to the logged total. See COSTS.html for the workload-ratio projection.
  • Commits vs. PRs: 624 total commits on main, of which 319 are PR squash-merges and 305 are direct. The 305 split as 117 pre-PR-workflow commits (before the first PR landed on 2026-04-13, when main was unprotected) plus 188 post-PR-workflow direct commits. The latter break down (mutually exclusive) as ~95 direct-commit-style (fix/docs/test/feat/refactor/chore via /commit direct or non-PR /quickfix, ~50%), ~54 /run-plan cherry-pick-mode phase commits (~29%), 36 canary plan-execution chores (~19%), and 3 infra/build commits.
  • Sessions vs. subagents: "Top-level sessions" are interactive Claude Code REPL sessions; "subagent dispatches" are isolated agents the orchestrator spawned for impl/verify/review work.

What this doesn't measure

Wall-clock time, human review effort, the Claude.ai chat sessions used for architecture discussions outside Claude Code, or the pre-2026-03-26 prototyping that fed into the initial commit. The numbers above are bounded to: this repo, Claude Code's JSONL transcripts, and Anthropic's published per-model list prices — not actual billed amount.

26 skills (24 user-facing + 2 helpers), 624 commits / 319 merged PRs, 97 test scripts, and ~$19,353 in logged Claude Opus 4.7 + Haiku 4.5 list-price equivalent — a body of evidence about what disciplined-agent engineering actually looks like.
