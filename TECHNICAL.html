Code Composition

The bulk of zskills is prose, not code. Skill bodies are markdown that teaches Claude how to drive a workflow — they read more like detailed checklists than implementations. The shell scripts are thin glue.

Methodology

Code/test/commit counts

All reproducible from a clean checkout of main at 283db23 (the merge-base this branch was cut from):

find skills block-diagram -type f \( -name "*.md" -o -name "*.sh" -o -name "*.py" \) -exec cat {} + | wc -l
find tests -type f -name "*.sh" -exec cat {} + | wc -l
find hooks -type f -name "*.sh*" -exec cat {} + | wc -l
git rev-list --count main
git log --oneline main | grep -cE '\(#[0-9]+\)'
gh issue list --state all --limit 1000 --json number | python3 -c 'import json,sys; print(len(json.load(sys.stdin)))'

Commits vs. PRs

624 total commits on main, of which 319 are PR squash-merges and 305 are direct. The 305 split as 117 pre-PR-workflow commits (before the first PR landed on 2026-04-13, when main was unprotected) plus 188 post-PR-workflow direct commits. The 188 break down (mutually exclusive) as ~95 direct-commit-style (fix/docs/test/feat/refactor/chore via /commit direct or non-PR /quickfix, ~50%), ~54 /run-plan cherry-pick-mode phase commits (~29%), 36 canary plan-execution chores (~19%), and 3 infra/build commits.

What this doesn't measure

Wall-clock time, human review effort, the Claude.ai chat sessions used for architecture discussions outside Claude Code, the pre-2026-03-26 prototyping that fed into the initial commit, or cost — see the Cost Estimate.

26 skills (24 user-facing + 2 helpers), 624 commits / 319 merged PRs, 97 test scripts — a body of evidence about what disciplined-agent engineering looks like.
