Cost & Tokens

Z Skills is itself built using Z Skills. We have Claude Code session JSONL transcripts for most of the development, with token counts per assistant turn. Here is the spend.

Honest caveats — read these before the headline numbers. JSONL coverage begins 2026-04-18 (cc-session-logger was installed mid-stream); the first ~23 days of dev (2026-03-26 → 2026-04-17) has no logged tokens. Cost numbers below therefore underestimate true spend. Prices use Anthropic's published per-model rates: Opus 4.7 ($15/$75/$18.75/$1.50 per MTok for input/output/cache-write/cache-read) for the 95,056 Opus turns, Haiku 4.5 ($1/$5/$1.25/$0.10 per MTok) for the 5,811 Haiku subagent turns. Zero Opus 4.6 turns in the log — JSONL coverage began after 4.7 became default. Actual billing depends on contract and any volume discounts. "Per-PR" figures use total spend ÷ merged PRs as a coarse divisor; the numerator includes exploration, failed attempts, and unmerged work. Concretely: the logged window (2026-04-18 → 2026-05-20, ~32 days) burned ~$1,553/day. If pre-2026-04-18 ran anywhere near that rate, true Opus spend is plausibly closer to $85k than the $49.8k headline — early-repo days were probably less intense than mid-stream, so treat $85k as a soft upper bound, not a tight estimate.

Cache Effectiveness

Z Skills relies heavily on Anthropic's prompt-cache. CLAUDE.md, SKILL.md bodies, and recent session context all live in cache windows; each subagent dispatch hits the cache instead of re-paying full input rates.

Methodology

Code/test/commit counts

All reproducible from a clean checkout of main at 283db23 (the merge-base this branch was cut from):

find skills block-diagram -type f \( -name "*.md" -o -name "*.sh" -o -name "*.py" \) -exec cat {} + | wc -l
find tests -type f -name "*.sh" -exec cat {} + | wc -l
find hooks -type f -name "*.sh*" -exec cat {} + | wc -l
git rev-list --count main
git log --oneline main | grep -cE '\(#[0-9]+\)'
gh issue list --state all --limit 1000 --json number | python3 -c 'import json,sys; print(len(json.load(sys.stdin)))'

Tokens & cost

Scanned every JSONL file under ~/.claude/projects/*zskills*/ (1,393 files across 8 project working dirs — main repo + 7 ephemeral worktree-spawned project dirs), extracted the usage field from each assistant turn, summed by category, applied Opus rates.

  • Rate basis: Anthropic's published per-model pricing applied per turn: Opus 4.7 ($15/$75/$18.75/$1.50 per MTok input/output/cache-write/cache-read) for the 95,056 orchestrator turns, Haiku 4.5 ($1/$5/$1.25/$0.10 per MTok) for the 5,811 Haiku subagent turns. Real billing may differ (volume discounts, contract terms).
  • Coverage gap: First commit on main is 2026-03-26; earliest logged JSONL turn is 2026-04-18. Roughly 23 days of dev is unlogged — expect actual spend to be moderately higher than the $49.8k figure.
  • Commits vs. PRs: 624 total commits on main, of which 319 are PR squash-merges and 305 are direct (117 pre-PR-workflow before 2026-04-13 plus 188 canary plan-executions and /commit direct-mode commits). The ratio commits-per-PR is ~2× because each PR squashes its branch's commits into one on main.
  • Sessions vs. subagents: "Top-level sessions" are interactive Claude Code REPL sessions; "subagent dispatches" are isolated agents the orchestrator spawned for impl/verify/review work.
  • Cost per merged PR: $49,782 ÷ 319 merged PRs ≈ $156 / PR. This includes exploration, planning, reviews, failed attempts, and the not-yet-merged work — not just successful PRs — so the real "cost of a successful merged PR" is somewhat lower. Take as a rough order-of-magnitude.

What this doesn't measure

Wall-clock time, human review effort, the Claude.ai chat sessions used for architecture discussions outside Claude Code, or the pre-2026-03-26 prototyping that fed into the initial commit. The numbers above are bounded to: this repo, Claude Code's JSONL transcripts, Opus list prices.

$49.8k of Claude Opus → 26 skills (24 user-facing + 2 helpers), 624 commits / 319 merged PRs, 97 test scripts, and a body of evidence about what disciplined-agent engineering actually costs.
