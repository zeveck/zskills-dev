What it actually cost to build Z Skills, computed from Claude Code session JSONL transcripts at published Anthropic rates. Every figure traceable to a token total and a rate.

Topline

Read this before the headline. All figures below are LOGGED spend only. Methodology

Rate source

All rates fetched 2026-05-20 from Anthropic's published API pricing page (platform.claude.com/docs/en/docs/about-claude/pricing):

Claude Opus 4.7  → $5 input / $25 output / $6.25 5m-CW / $10 1h-CW / $0.50 CR per MTok
Claude Haiku 4.5 → $1 input / $5 output  / $1.25 5m-CW / $2  1h-CW / $0.10 CR per MTok

Earlier model tiers (Opus 4.0 / 4.1, now deprecated) are priced at 3× these rates. Z Skills development used Opus 4.6 in the unlogged pre-2026-04-16 era and Opus 4.7 thereafter; both bill at the Opus 4.5+ tier above.

Token totals

Scanned 1,518 JSONL files across 8 project working directories (~/.claude/projects/-workspaces-zskills/ + 7 ~/.claude/projects/-tmp-zskills-*/ ephemeral worktree-spawned dirs). For each assistant turn, extracted the usage object's per-model and per-cache-tier fields. usage.cache_creation.ephemeral_5m_input_tokens and usage.cache_creation.ephemeral_1h_input_tokens give the structured tier split; the flat cache_creation_input_tokens field sums to within ~12k tokens of the decomposed total (~0.001% drift, immaterial).

Multipliers applied

  • Data residency: 1.0× (default global routing assumed; not US-only).
  • Fast mode: 1.0× (never used in this development).
  • Batch API: 1.0× (interactive sessions, no batch discount).
  • Extended thinking: not separately metered; output_tokens already captures any thinking-mode generation (no separate thinking_tokens field exists in usage across all 105,250 logged turns).

What this doesn't measure

Pre-2026-04-18 development (~23 days, ~1/3 of project elapsed time) is unlogged. Wall-clock time, human review effort, Claude.ai chat sessions for architecture discussion outside Claude Code, and the pre-repo prototyping that fed the initial commit are all excluded. Real billing depends on contract, any volume discounts, and other terms; the numbers above are at published list prices.

Verification

All figures here were independently audited by two automated agents reviewing the JSONL data, the rate source, and the arithmetic. Reproducibility scripts left at /tmp/q1q2.py, /tmp/q2_totals.py, /tmp/q3.py during the audit. Discrepancy vs. the original deck's $49,782 figure traced to deprecated-tier rates (Opus 4.0/4.1 at 3× current rates) being used in error.

$19,353 of logged Claude Opus 4.7 + Haiku 4.5 spend → 26 skills, 624 commits / 319 merged PRs, 97 test scripts. Plus an unmeasured Opus 4.6 era (~23 days, 2026-03-26 → 2026-04-17) that pre-dates session logging.
