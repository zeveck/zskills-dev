Code Composition

The bulk of zskills is prose, not code. Skill bodies are markdown that teaches Claude how to drive a workflow — they read more like detailed checklists than implementations. The shell scripts are thin glue.

Note that SKILL.md prose has shrunk (23,239 → 17,648 since 2026-05-21, −24%) while total skill-tree LOC grew (42,759 → 53,483, +25%). The skill-body markdown stays load-bearing for orchestration; the extracted files load on-demand. The 2026-05-22 → 2026-06-05 window also saw two full-skill removals: /quickfix (869 lines, in #1073) and /doc (in #1061).

Methodology

Code/test/commit counts

All reproducible from a clean checkout of main (HEAD as of 2026-06-05):

find skills block-diagram -type f \( -name "*.md" -o -name "*.sh" -o -name "*.py" \) -exec cat {} + | wc -l
find tests -type f -name "*.sh" -exec cat {} + | wc -l
find hooks -type f \( -name "*.sh" -o -name "*.json" \) -exec cat {} + | wc -l
git rev-list --count main
git log --oneline main | grep -cE '\(#[0-9]+\)$'
gh issue list --state all --limit 2000 --json number | python3 -c 'import json,sys; print(len(json.load(sys.stdin)))'

Independent re-counts via different command paths (git ls-files | xargs wc -l instead of find ... -exec cat | wc; git log --oneline | wc against git rev-list --count; gh pr list --state merged against the regex on log) match all 13 reference figures. The merged-PR count via gh pr list --state merged returns 738 (vs the 739 regex count) — a 1-PR delta most likely from a closed-cherry-picked PR; the regex-on-log count is what's reported here, consistent with prior snapshots' methodology.

Commits vs. PRs

1,044 total commits on main, of which 739 are PR squash-merges and 305 are direct. The 305 direct-commit count is unchanged since the 2026-05-21 snapshot — all 335 new commits in the 2026-05-22 → 2026-06-05 window went through PRs (main_protected: true). The 305 split as 117 pre-PR-workflow commits (before the first PR landed on 2026-04-13, when main was unprotected) plus 188 post-PR-workflow direct commits. The 188 break down (mutually exclusive) as ~95 direct-commit-style (fix/docs/test/feat/refactor/chore via /commit direct, ~50%), ~54 /run-plan cherry-pick-mode phase commits (~29%), 36 canary plan-execution chores (~19%), and 3 infra/build commits.

What this doesn't measure

Wall-clock time, human review effort, the Claude.ai chat sessions used for architecture discussions outside Claude Code, the pre-2026-03-26 prototyping that fed into the initial commit, or cost — see the Cost Estimate.

26 skills (13 user-facing + 10 helpers + 3 add-ons), 1,044 commits / 739 merged PRs, 237 test scripts — a body of evidence about what disciplined-agent engineering looks like.
