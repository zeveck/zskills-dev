# Block Diagram Add-On Skills

Documentation for the 4 **add-on** skills in the block-diagram package. These are not part of the core skill set -- they ship separately and are installed via `/update-zskills install --with-block-diagram-addons`.

## Quick Reference

| Skill | Description | Docs |
|-------|-------------|------|
| [`/add-block`](add-block.md) | Step-by-step guide (steps 0--12) for adding new block types | [Details](add-block.md) |
| [`/add-example`](add-example.md) | Create example models for one or more block types, including model construction, registration, unit + codegen tests, screenshots, and verification | [Details](add-example.md) |
| [`/model-design`](model-design.md) | Layout guidelines for well-laid-out block diagrams and state charts, based on MAAB/NASA and graph-drawing standards | [Details](model-design.md) |
| [`/review-feedback`](review-feedback.md) | Review exported feedback JSON from the in-app feedback panel and selectively file GitHub issues | [Details](review-feedback.md) |
